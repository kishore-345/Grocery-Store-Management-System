# Grocery Store Management System

## Project Overview

The Grocery Store Management System is a SQL-based database project developed to manage and analyze grocery store operations efficiently. The project focuses on handling customer records, product management, sales tracking, suppliers, employees, and generating business insights using SQL queries.

This project was developed as part of our learning journey in SQL and Data Analytics at Innomatics Research Labs.

---

## Objectives

* Design and implement a relational database system
* Manage customers, products, suppliers, employees, and orders
* Analyze customer purchasing behavior and sales trends
* Identify top-selling products and high-value customers
* Evaluate supplier and employee performance
* Generate business insights using SQL queries

## Key SQL Analysis Performed

* Top Customers by Spending
* Rank Customers by Spending
* Products with Highest Sales Quantity
* Revenue Generated by Each Product
* Top Product in Each Category
* Monthly Revenue Trends
* Weekday vs Weekend Orders
* Supplier Revenue Analysis
* Employee Sales Ranking
* High & Low Value Orders

## Business Insights Generated

* Top customers contribute major revenue
* Certain product categories consistently perform better
* Supplier contribution varies across products
* Employee performance differs based on sales handled
* Monthly and seasonal trends affect sales performance
